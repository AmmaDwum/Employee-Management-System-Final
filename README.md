# Employee Management System (EMS)

**Author:** Ama Mensah-Dwumfua

## Overview
This repository contains the final demo submission for the Employee Management System.

## Technology
- Java
- Java file handling
- Text files for data storage

## Main Features
- Add Employee
- View Employees
- Record Attendance
- View Attendance Records

## Folder Structure
- `1_code` contains the Java program and text files.
- `2_unit_testing` contains unit testing notes.
- `3_integration_testing` contains integration testing notes.
- `4_data_collection` contains sample data notes.
- `5_documentation` contains the final PDF documentation, brochure, and slides.

## How to Run
Open the `1_code` folder and run:

```bash
javac Main.java
java Main
```
