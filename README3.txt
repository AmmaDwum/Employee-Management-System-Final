Integration Testing

This folder explains integration testing for the EMS project.

The main integration test checks that the user menu, Java code, and text files work together.

Integration workflows tested:
1. Add Employee -> View Employees
   The system saves employee data and then retrieves it from employees.txt.

2. Record Attendance -> View Attendance
   The system saves attendance data and then retrieves it from attendance.txt.

3. Full Demo Workflow
   Add Employee -> View Employees -> Record Attendance -> View Attendance

Future improvement:
A later version could include automated integration test scripts.
