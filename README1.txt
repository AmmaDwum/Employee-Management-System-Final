Employee Management System (EMS)
Java + Text File Version

This folder contains the source code for the Employee Management System.

Files:
- Main.java
- employees.txt
- attendance.txt
- README1.txt

How to run:
1. Make sure Java is installed.
2. Open a terminal or Command Prompt in this folder.
3. Compile the program:
   javac Main.java
4. Run the program:
   java Main
5. Use the menu to add employees, view employees, record attendance, and view attendance records.

This version stores data in text files:
- employees.txt stores employee information.
- attendance.txt stores attendance information.
